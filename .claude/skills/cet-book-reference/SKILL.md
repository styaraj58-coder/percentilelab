# CET book reference library

These are scanned coaching-institute books (Cetking-branded) the user supplied as
**private reference material only** — for writing and reviewing Percentile Lab's
own CET test content. They live outside the git repo and must never be uploaded,
published, or otherwise made available on the site itself.

All files are large, scanned-image PDFs (20–55MB, up to ~130 pages). Never call
`Read` on a whole file — always pass a `pages` range (max 20 pages per call), and
read only the chapter(s) relevant to the questions you're currently writing.

## How to use this

- **Topic coverage check**: when building a new section (Quant/LR/Verbal/DI), skim
  the relevant chapter list above to confirm the test covers a representative
  spread of sub-topics, not just a narrow slice.
- **Style and difficulty reference**: skim a few worked examples in the relevant
  chapter to calibrate phrasing, option format (plain values vs. lettered A–D),
  and difficulty level against what CET actually asks.
- **Do not copy verbatim.** These are someone else's copyrighted coaching
  material. Write original questions inspired by the patterns and topics shown —
  never transcribe a book's question, passage, or figure directly into a test
  uploaded to the site. This mirrors the copyright concern already flagged once
  in this project (a screenshot lifted from a third-party TCS sample paper in
  "Aptitude test 1" — cropped and kept only because the user explicitly accepted
  that tradeoff for one already-sourced question; don't create new instances of
  that problem here).
- **Still verify math independently.** As with every test uploaded so far in this
  project, don't trust a book's stated answer key blindly — recompute anything
  numeric before publishing, the same way past uploads caught real answer-key
  errors (e.g. Aptitude test 1's bank-loan and pie-chart questions).
